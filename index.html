保存收藏、词组、查询记录、释义与备注，以及阅读、显示和发音偏好等个人设置。文件很小，适合日常迁移与恢复。

❓ 一分钟上手
LingoFlow V0.5.5
1. 首次准备首次进入可选择“自动加载词库”“手动导入”或“稍后再说”；完成后词库保存在本机，日常查询无需联网。
2. 开始阅读粘贴英文或拖入 TXT → 生成文章 → 点击不会的词。
3. 查询 ≠ 收藏点词只进入“查询记录”；想重点学习的单词可以收藏，也可以划选 2–20 个英文词收藏为词组。
4. 收藏可自定义单词和词组都可编辑释义、上下文和备注；词库未收录的表达也能收藏。
5. 换电脑优先导出“学习数据备份”，在另一台电脑选择“智能合并”；离线词库可以重新准备。
6. 听发音可在“设置”中提前选择默认英语声音和语速，选择会自动保存，并统一用于单词、词组和收藏朗读。
7. 导入 TXT把 TXT 拖进大区域，或者直接点击该区域选择文件；载入后再生成文章。
快捷键 Ctrl/⌘ + K：直接查词 Ctrl/⌘ + F：阅读时定位原文搜索 Esc：关闭弹窗 / 释义卡
📝 更新日志
记录每个版本真正改了什么，方便以后继续迭代。
V0.5.5
2026-08-17
  • 默认英语声音与语速现在会自动保存，刷新或重新打开网站后继续使用。
  • 正文单词、查词卡片、词组、收藏和查询记录等朗读入口统一使用同一套发音设置。
  • 设置中无需先生成文章，即可选择默认声音、语速并试听。
  • 新用户首次进入不再自动下载词库，可选择“自动加载 / 手动导入 / 稍后再说”。
  • 自动加载支持安全取消、失败重试和断点续传，并与手动导入互斥，避免同时写入本地词典。
  • 无词典时仍可阅读；查询会提示准备词库，不会偷偷下载。
  • 老用户仍可直接导入完整未拆分的 ECDICT CSV 和原 Lemma 文件。
V0.5.4
2026-08-17
  • 阅读正文可划选 2–20 个英文词，收藏词组或朗读整个选区。
  • 收藏词组时自动保存所在原句，并新增 WORD / PHRASE 类型标签。
  • 词组支持编辑释义、备注、朗读和删除；相同词组会自动去重。
  • 学习数据备份和恢复兼容词组收藏，不影响原有单击查词。
V0.5.3
2026-08-17
  • Web 版支持自动准备 ECDICT 和 Lemma，并保存到浏览器 IndexedDB。
  • ECDICT 拆分为多个 Web 分片分发，最终包含 770,611 条记录。
  • Lemma 按实际唯一键记录 182,670 条映射。
  • 支持 ECDICT 分片断点恢复，中断后可从已完成进度继续；完成后日常查询无需重复下载词库。
V0.5.2 Stable Patch 2
2026-08-11
  • 深色模式完整打磨：修复“一分钟上手”白色卡片及文字对比问题。
  • 统一修复搜索候选、原文搜索框、收藏标签/掌握状态、备份区域、弹窗关闭按钮等深色显示。
  • 修复深色模式下词典导入进度条对比度不足的问题。
  • 智能合并说明更严谨：V0.5.2 起的新查询按唯一事件 ID 精确去重，旧历史作为基线保留。
  • TXT 拖拽提示明确为“先载入，再生成文章”，避免操作误解。
  • 旧版学习备份增加稳定内容签名：同一个旧备份即使复制或改名，也不会被重复当成两份历史基线。
  • 完整备份文案明确为“整套恢复/覆盖”，避免和日常智能合并同步混淆。
V0.5.1
体验与数据安全升级
  • 词形还原展示：明确显示原形、当前词形释义和词形变化。
  • 搜索增强：输入即提示、方向键选择、回车查询、⌘/Ctrl + K 快速聚焦。
  • 原文全文定位：查找文章中的单词，并在命中位置之间跳转。
  • 查询记录：文章点击和搜索自动留痕，并支持最近/高频/最早/A–Z 排序。
  • 数据迁移：支持学习数据备份，以及包含词库的完整备份与恢复。
  • 存储明细：可分别估算 ECDICT、Lemma、查询记录和收藏的本地数据大小。
  • 稳定性收尾：优化连续点词朗读，减少 Chrome / Windows 偶发“点了不读”的情况。
  • 搜索排序：优先展示 IELTS、四六级、常用正常词，降低缩写、人名、医学冷门词的排序。
  • 存储说明：增加“已知数据合计”和“数据库开销 / 其他”的估算。
  • 备份界面收尾：学习数据与完整备份的导入/导出按钮明确分组，减少误操作。
  • 项目署名：正式加入作者 Timbo 与版权信息。
  • 学习逻辑重构：自动“生词本”改为查询记录；收藏改为用户主动操作。
  • 上下文收藏：收藏单词时自动带出所在句子，收藏本内可修改句子并填写个人备注。
  • 长文阅读：右侧释义栏改为随当前屏幕固定，阅读长文章时不用回到顶部找释义。
  • 查询记录排序：新增最近查询、高频查询、最早遇到和 A–Z。
  • 收藏本紧凑化：默认只展示释义、上下文和已有备注预览；点“编辑”才展开完整文本框。
  • 收藏编辑体验：一次只展开一个收藏，保存后自动恢复折叠浏览状态；没有备注时不再占大块空白。
  • 个人词卡：词库未收录的英文词也可以收藏，并同时进入查询记录。
  • 自定义收藏：可自行修改音标/发音说明、词性、中文释义、上下文和个人备注。
  • 贡献署名：加入 Jane. Z — Testing, Bug Reports & Product Feedback。
  • V0.5.2 智能合并：每次新查询生成唯一事件 ID，跨电脑反复导入时自动去重，不再重复累加旧查询。
  • 阅读体验：新增字体大小、行距、深色模式、阅读进度条、返回顶部和快捷键。
  • 收藏管理：新增标签和“已掌握”状态，可筛选与排序。
  • 文件体验：TXT 支持拖拽导入。
  • 数据安全：新增 7 天备份提醒和学习数据“智能合并 / 预览合并 / 完全覆盖”三种导入方式。
  • 帮助中心：新增一分钟上手和快捷键说明。
