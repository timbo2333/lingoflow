❓ 一分钟上手
LingoFlow V0.7
1. 开始查词在线 Core Dictionary 打开即用，无需先下载；如需断网查询更多词汇，可在设置中下载完整离线词典。
2. 开始阅读粘贴英文或导入 TXT，点击“开始阅读”；文章会自动保存到“我的文章”。
3. 我的文章与继续阅读阅读进度会自动保存，再次打开可恢复位置；“继续阅读”可快速回到最近阅读中的文章。
4. 管理文章可查看阅读状态、按状态筛选、搜索标题或来源文件名，并从“最近删除”恢复文章。
5. 阅读与学习点词查词、朗读并收藏单词或词组；设置中的“完整数据备份”可保存文章与进度、收藏、学习状态、查询记录和偏好。
6. 可选云同步无需登录也能使用；登录后可选择同步收藏与学习状态。本地已有收藏首次关联账号前会先征求你的确认。
快捷键 Ctrl/⌘ + K：直接查词 Ctrl/⌘ + F：阅读时定位原文搜索 Esc：关闭弹窗 / 释义卡 在“我的文章”中使用浏览器返回，会先退出最近删除或关闭文章窗口，不会直接离开页面。
📝 更新日志
记录每个版本真正改了什么，方便以后继续迭代。
V0.7
2026-09-06
  • 新增 Supabase 账号登录，刷新页面后会自动恢复登录状态。
  • 可选择开启收藏云同步；关联本地工作区前会先征求确认，未经同意不会上传。
  • 收藏可在同一账号的设备之间同步，新设备登录后会自动恢复已有收藏。
  • “已掌握”和“学习中”状态可以随收藏跨设备同步。
  • 新增同步状态提示与手动重试；网络不可用时仍可优先使用本地数据。
  • 优化阅读页工具栏间距，让查找、语速和朗读控件排列更紧凑。
V0.6
2026-08-19
  • 新增“我的文章”，开始阅读后文章会自动保存。
  • 阅读进度会自动保存，重新打开文章时可恢复位置并继续阅读。
  • 新增阅读状态和状态筛选，查找不同进度的文章更方便。
  • 支持按文章标题或来源文件名搜索。
  • 新增“最近删除”，可以恢复误删的文章。
  • 改进“我的文章”的浏览器返回体验，返回时会先退出当前文章窗口。
V0.5.5
2026-08-17
  • 默认英语声音与语速现在会自动保存，刷新或重新打开网站后继续使用。
  • 正文单词、查词卡片、词组、收藏和查询记录等朗读入口统一使用同一套发音设置。
  • 设置中无需先生成文章，即可选择默认声音、语速并试听。
  • 新用户首次进入不再自动下载词库，可选择“自动加载 / 手动导入 / 稍后再说”。
  • 自动加载支持安全取消、失败重试和断点续传，并与手动导入互斥，避免同时写入本地词典。
  • 无词典时仍可阅读；查询会提示准备词库，不会偷偷下载。
  • 老用户仍可直接导入完整未拆分的 ECDICT CSV 和原 Lemma 文件。
V0.5.4
2026-08-17
  • 阅读正文可划选 2–20 个英文词，收藏词组或朗读整个选区。
  • 收藏词组时自动保存所在原句，并新增 WORD / PHRASE 类型标签。

  • 支持 ECDICT 分片断点恢复，中断后可从已完成进度继续；完成后日常查询无需重复下载词库。
